Tentang saya

Kerja saya ada di dua sisi: simulator jaringan untuk latihan dan NOC, serta infrastruktur server yang menjalankan semuanya. Keduanya saya perlakukan seperti pekerjaan nyata — perangkat, port, kabel, dan status link harus masuk akal.

Mulai dari merancang topologi, menulis kodenya, sampai deploying, hardening, dan memantau uptime. Kalau belum bisa dites di server sungguhan, belum selesai.

Selain itu: web full-stack, Web Audio untuk ambience, dan otomasi CLI untuk pekerjaan berulang.
